# Proposal Review Loop Lessons

Updated: 2026-10-08

## L1 — Positive wording can still be review feedback

Phrases such as 「いいけど」「結構。ただし」「OK、でも」 are not approval when they also change the proposal.

## L2 — Never approve an agent-inferred revision

If feedback changes P-001, the agent may draft P-002, but P-002 remains unapproved until it is shown and explicitly approved.

## L3 — Re-present the whole revised proposal

Do not ask the user to approve only a hidden delta. Present the full revised proposal so the approved object is clear.

## L4 — Ambiguity stops implementation

If a reply could mean either review feedback or approval, ask. Do not infer execution authority.

## L5 — Exact approval survives chat boundaries

Once the exact unchanged revision is explicitly approved and recorded, do not ask for the same approval again merely because the chat changed.
