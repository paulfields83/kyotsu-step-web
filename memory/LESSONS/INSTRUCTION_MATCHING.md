# Instruction Matching Lessons

Updated: 2026-10-08

## L1 — Similar is not equal

If a user phrase resembles a registered GitHub command, do not silently reinterpret it.

Show:
- the candidate Command ID,
- its canonical phrase,
- its behavior,

then ask whether this instance should be treated as that command.

## L2 — Missing important commands stop normal work

When a required GitHub operation is not represented in the instruction dictionary, do not improvise a new authority path. Stop normal work and repair the instruction layer first.

## L3 — Alias creation is explicit

Repeated natural-language phrasing does not become an alias automatically. Alias registration requires user approval.
