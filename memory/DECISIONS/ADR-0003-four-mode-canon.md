# ADR-0003 — Keep four educational mode canons separate

Status: ACCEPTED-FOR-DRAFT  
Date: 2026-10-05

## Context

Past work repeatedly mixed rules between subjects and between textbook learning and guided practice.

## Decision

Maintain separate canonical specs for:
- Mathematics Textbook
- Mathematics Practice
- Physics Textbook
- Physics Common-Test Guided Practice

Only genuinely shared principles may be factored upward.

## Consequence

A successful pattern in one mode is not automatically a rule in another. Cross-mode reuse requires explicit review.
