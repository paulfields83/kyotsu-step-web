# ADR-0007 — Correction Handoffs Include Review Links

Status: ACCEPTED
Date: 2026-10-10

## Decision

Whenever correction work reaches a user-reviewable stopping point, the final handoff must include at least one usable review link.

Priority:
1. live/rendered app or preview;
2. Pull Request;
3. branch or exact GitHub location.

If the preferred link is unavailable, state that and provide the best fallback.

This applies to both DONE work and review-gate stops such as VERIFYING pilots.
