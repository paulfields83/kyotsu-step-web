# TEST PLAN

## 自动检查

- TypeScript：领域与 UI 的严格类型；
- ESLint：React Hooks、未使用代码与静态问题；
- Vitest：Schema 交叉引用、学习首次作答、判分、分析、推荐、日中题库稳定 ID 与判分结构一致性；
- Playwright：阶段 0 smoke、路由、学习对/错/解析/刷新/完成、模拟无反馈/标记/刷新/交卷/超时、历史/管理、全局语言切换和语言偏好恢复；
- Production build：每阶段最终门禁。

## 设备矩阵

Playwright 主项目使用 Pixel 7。阶段 2/11 额外检查 390×844、430×932、768×1024、1440×900；断言无页面横向溢出、固定导航不遮挡末尾内容。

## 手工浏览器清单

- 逐空首答正确、首答错误、错误后继续、解析打开/关闭、滚动位置、刷新恢复、全部完成；
- 模拟正常/未答交卷、取消、切题、稍后检查、刷新计时、多选、数值、超时；
- 键盘焦点、按钮最小尺寸、长日文、公式/表格横向容器、图片 alt；
- 清空数据后的空态、非法 JSON 导入、题目 revision 识别。
- 中文学习与模拟完整流程、日中题目正文/选项/解析、答题中切换语言后的 session 连续性、刷新后的语言偏好、`html lang` 和双语触控尺寸。

## 缺陷等级

- P0：数据丢失、错误判分、答案泄露、主流程不可完成；
- P1：主页面不可达、刷新恢复失败、严重溢出/遮挡、无障碍阻断；
- P2：次要文案、非阻断视觉偏差、参考附件证据缺口。
