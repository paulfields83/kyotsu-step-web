# Proposals — W-GOV-004

## P-001 — Correction review link handoff

Status: APPROVED
Created: 2026-10-10

### Rule

At the end of every correction work cycle that reaches a user-reviewable state, the assistant must include at least one direct review link in the final handoff.

Priority:
1. rendered app / preview / directly reviewable screen;
2. Pull Request;
3. branch or exact GitHub location if no better review surface exists.

If the highest-quality link does not exist, say so and provide the best available fallback.

The link requirement applies whether the Work is DONE or paused at a user review gate.
