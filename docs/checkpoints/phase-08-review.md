# Phase 08 Review — PASS

## 目标

让分析、错题和历史只依据保存的 Learning/Simulation Attempt 动态计算，不使用写死成绩。

## 已完成

- 分析汇总学学习初回正确率、模拟正确率、完成率、平均回答时间、解析利用率和总记录时间；
- 知识与解题行为分开聚合，显示作答数、定着度、反复错误和可进入的标签详情；
- 错题状态按“复习中 → 类题 1 回合格 → 定着”推进，只有后续实际全对记录能改变状态；
- 历史按 Asia/Tokyo 排序，保留 session、题名、revision、初回成绩、模拟得分与未回答数量；
- 零数据时显示明确空状态，不伪造进度。

## 检查证据

- `analytics.test.ts`：指标聚合、解析率、响应时间和三段错题状态均通过；
- `analytics-history.spec.ts`：从真实 selfCheck 误答完成后，分析 0%、maximum 详情、复习中和 rev.1 历史全部出现；
- 16 项单元测试、类型、ESLint 和生产构建通过；
- 浏览器实测：此前真实模拟 3/6 的记录生成 50% 模拟正确率、maximum 50 定着度和对应技能数据。

## 发现并修复

分析页对零学习记录但有模拟记录的学习完成率明确显示 0%，避免除零或伪造 100%；不存在题库定义时历史仍使用 Attempt 快照显示题名与版本。

## 风险与结论

定着度为公开的本地规则分数，样本少时波动较大；界面同时显示回答数，避免将小样本误解为稳定能力。无未解决 P0/P1。阶段结论：**PASS**，允许进入阶段 9。
