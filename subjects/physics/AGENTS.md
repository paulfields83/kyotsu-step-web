# Physics Agent Router

Scope: `subjects/physics/**`

root `AGENTS.md` と governance/navigation の後に読む。

## Mode routing

- 教科書・学習モード → `textbook/SPEC.md`
- 共通テスト型 guided practice → `practice/SPEC.md`

## Hard boundaries

- Textbook は概念形成を目的とする。
- Practice は原問題を保持した推論訓練を目的とする。
- Simulation は無誘導の本番型であり、Practiceとは別。
- 古い章ID（例: 1A〜1G、旧1D等）は内容正本ではない。現在のchapter mapが確定するまで識別子として再利用しない。
- 物理量・符号・ベクトル・図の向き・境界条件を見た目の都合で変更しない。
- 図と式を別々に設計せず、どの理解ノードを支えるか先に決める。
