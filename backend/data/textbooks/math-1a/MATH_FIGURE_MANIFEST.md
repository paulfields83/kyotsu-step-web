# 数学 I・A 学習モード Figure Manifest

作成方針:
- App の最終本文を「何を説明するか」の基準にする。
- Word 母本 / 啓林館 α数学I・A / Guide を数学内容の照合基準にする。
- 数学関係を先に固定し、見栄えのために点・線・角・包含関係を変えない。
- 空欄の答えを画像だけで直接漏らさない。
- SVG をコード生成し、alt / caption を必ず付ける。
- ラベルと図形境界を重ねない。色だけに意味を依存させない。

## V2 厳格再制作（2026-09-30）

今回、以下の図を「見た目で配置」ではなく数学条件から再制作した。

- 2次関数: 定義域と値域 / 頂点形式 / 平行移動・対称移動
- 図形と計量: 三角比の直角三角形
- データの分析: y=ax+b によるデータ変換
- 図形の性質: 角の二等分線 / 重心 / 外心・内心・垂心 / 五心まとめ / チェバ / メネラウス / 両定理の逆 / 辺と角 / 内接四角形 / 接弦定理 / 方べき / 2円 / 三垂線
- 集合と命題: ド・モルガンの法則

### V2 QA
- 関数図: 頂点・軸・平行移動・対称移動を同一の二次式の座標変換として固定。
- 角の二等分線: BD:DC=AB:AC となる点 D を使用。
- 重心: 3辺の中点へ引いた3中線の交点を使用。
- 外心・内心・垂心: それぞれ垂直二等分線 / 角の二等分線 / 高さを表示。
- チェバ: D∈BC, E∈CA, F∈AB かつ AD,BE,CF が同一点 P を通る構図。
- メネラウス: D,E,F を三辺または延長と同一の横断線との交点として配置。
- 内接四角形: 4点を同一円周上から生成。
- 方べき: A,B,C,D を割線と円の実交点として配置し、接線 PT も併記。
- 2円: 共通弦⊥中心線、半径⊥共通接線を分けて表示。
- 三垂線: 3D 座標上で PH⊥α, l⊥HQ, l⊥PQ を満たす構図を2D投影。
- ラベルは図形境界上に置かず、本文と同じ記号を使用。
